# Visual specification

White (#ffffff) canvas, evergreen (#004832) primary, ink (#093b2d), muted gray (#5c6865), orange (#dd590d) accent. Georgia editorial headings; Arial UI. Maximum content width 1380px, desktop gutters 5vw, 24px card gaps, 16px radii. Three columns above 1000px, two above 640px, one on small screens. Thin bottom borders, restrained shadows, outlined SVG icons. Search row, category tabs, results heading, photo cards follow the generated Explorer concept. Hover lifts are subtle; reduced motion disables them.

Required supporting pages extend the same system: split photo Home with CTA, photo-led Detail, Favorites cards/empty state, mock Profile with saved count. All controls and text are HTML. Production imagery intentionally uses a generated Adriatic hero plus locally bundled illustrative stock placeholders; images are not promises of actual bookable inventory.
